# ClipLite 多设备同步 · 操作指南

> 适用版本：协议 v0.4（2026-10）。本文面向使用者，按"先做什么、看到什么、再做什么"的顺序编写。
> 界面入口：托盘/主菜单 → 设置 → 左侧「同步」。

---

## 1. 概念（30 秒读完）

| 概念 | 说明 |
|---|---|
| 服务器 | 一台运行 `clipsync-server.exe` 的机器，所有设备都连它。地址形如 `ws://192.168.1.10:8765`（局域网）或 `wss://…`（公网/加密）。 |
| 同步房间 | 一个"组"。同一房间内的设备剪贴板互通。设备可以自己建房间（配对后即有），也可以加入别人的房间。 |
| 配对码 | 8 位大写字母+数字（不含 0/1/I/O，避免看错）。**10 分钟内有效、一次性使用、每设备最多同时 5 个**。 |
| 创始码 | 服务端管理员生成的特殊配对码。**第一台设备**必须用它完成首次配对（此时还没有任何房间）。 |
| 引入关系 | 房间里"谁邀请进来的谁"。你只能看到并移除**经你生成的配对码加入**的设备。 |

配对方向（重要）：
- **你想加入别人** → 你是"加入方"：填对方的码，点「加入」，等对方确认。
- **你想拉别人进来** → 你是"房主"：点「生成配对码」，把码给对方，在「待确认」里允许。

## 2. 首次部署（全新环境）

1. 在一台机器上启动服务端（`clipsync-server.exe`）。管理员需设置环境变量 `CLIPSYNC_ADMIN_PASSWORD`（**没有默认密码**）。
2. 浏览器打开服务端管理页（或调用管理接口），用管理员密码登录，生成一个**创始码**。
3. 在第一台设备的「设置 → 同步」页：
   - 填「服务器地址」（如 `ws://192.168.1.10:8765`）
   - 「对方配对码」填创始码 → 点「加入」
   - 创始码**无需确认**，立即配对成功，同步自动开启。
4. 之后的其他设备走第 3 节的日常流程。

## 3. 日常加入（已有房间）

### 场景 A：我要加入别人的房间

1. 对方设备（已在房间里）：同步页 →「邀请设备加入本房间」→ 点「生成配对码」→ 把 8 位码告诉你（10 分钟内有效）。
2. 你的设备：填服务器地址 → 填对方配对码 → 点「加入」。
3. 设备状态显示「等待对方确认…」；对方在「待确认」列表点「接受」。
4. 你这边状态变为「已配对 · 在线同步中」，剪贴板开始互通。

### 场景 B：我邀请别人进我的房间

1. 你的设备：点「生成配对码」，把 8 位码给对方。
2. 对方设备：填你的服务器地址 + 这个码 → 点「加入」。
3. 你的同步页「待确认」出现一行：`设备名（n 分钟前 申请）`，点「接受」或「拒绝」。
4. 接受后，对方出现在「设备管理」列表（经由本机加入的设备）。

### 场景 C：移除某个设备（踢出）

「设备管理」列表中该设备行 → 点「移除」→ 确认。
效果：立即吊销其令牌并断开连接，对方回到未配对状态。只能移除**经由本机配对码加入**的设备。

### 场景 D：本机退出同步

「设备管理」→「清除本机配对，停止同步」→ 确认。本机回到未配对状态，不影响房间内其他设备。

## 4. 设备状态说明

| 状态文字 | 颜色 | 含义 | 你该做什么 |
|---|---|---|---|
| 未配置：先在上方填写服务器地址 | 灰 | 服务器地址为空 | 填地址 |
| 未配对 · 正在检查服务器... | 灰 | 正在探测服务器可达性 | 稍等几秒 |
| 未配对 · 服务器连接正常，填入配对码后点「加入」 | 灰 | 网络通，但本机还没加入房间 | 找房主要码，填码加入 |
| 未配对 · 无法连接服务器，请检查地址与网络 | **红** | 地址不可达（服务端没开/IP 变了/防火墙） | 检查服务端是否运行、地址是否正确、ping 一下 |
| 已配对 · 正在提交加入申请 / 等待对方确认... | 橙 | 加入流程进行中 | 等对方在待确认里点接受 |
| 已配对 · 正在连接服务器 | 橙 | 已配对，WS 建立中 | 稍等，通常几秒内 |
| 已配对 · 在线同步中 | **绿** | 一切正常 | 无 |
| 已配对 · 离线（将自动重连） | **红** | 网络中断或服务端重启中 | 会自动重连；持续离线再查网络 |
| 已配对 · 同步已停用 | 灰 | 开关「启用同步」被关了 | 打开开关 |

## 5. 常见提示对照

| 提示 | 原因 | 处理 |
|---|---|---|
| 请先填写服务器地址，再填写对方设备生成的配对码。 | 两项都为空就点了「加入」 | 按提示填 |
| 请先填写服务器地址，例如 ws://192.168.1.10:8765 | 只填了码 | 补地址 |
| 请先填写对方设备「生成配对码」得到的 8 位配对码。 | 只填了地址 | 补码 |
| 配对失败：服务器地址无效（需 ws:// 或 wss://） | 地址格式不对 | 补全协议前缀 |
| 配对失败：无法连接服务器 | 服务端不通 | 见状态表红色行 |
| 配对失败：配对码不存在或已过期 | 码错了/超 10 分钟/已被使用 | 让对方重新生成 |
| 配对失败：请求过于频繁，请稍后再试 | 同一 IP 每分钟最多 5 次加入尝试 | 等 1 分钟 |
| 配对失败：失败次数过多，已临时锁定 | 连续错 10 次触发防爆破锁定（15 分钟） | 等 15 分钟，或重启服务端清除 |
| 本机还没有加入任何同步房间，无法生成配对码。 | 未配对就点了「生成配对码」 | 先完成配对（创始码或加入别人的房间） |
| 加入申请已过期，请重新提交。 | 申请超时未确认 | 重新走一遍加入流程 |
| 对方拒绝了对本机的加入申请。 | 房主点了拒绝 | 与房主沟通后重新申请 |

## 6. 安全限制（服务端强制）

- 加入接口按来源 IP 限速：**每分钟 5 次**；连续失败 **10 次**锁定该 IP **15 分钟**。
- 配对码：10 分钟 TTL、一次性、每设备并发最多 5 个、字符集去歧义（无 0/1/I/O）。
- 服务端不设默认管理员密码；未设 `CLIPSYNC_ADMIN_PASSWORD` 时管理接口直接拒绝。
- 被移除设备的令牌立即失效，无法再连接。

## 7. 仍不明白时

- 状态行红色 → 先解决网络，再谈配对。
- 状态行灰色「服务器连接正常」→ 剩下的只是拿到一个有效配对码。
- 更多技术细节见 `docs/clip-sync-protocol.md`（协议与接口定义）。
